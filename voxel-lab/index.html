Drag any viewport to rotate all three cameras together. Choose a single version for a larger view. Walk uses W A S D; Fly also uses Q / E. On phones, switch between versions with the top buttons.

The seven-metre storefront is generated from the same source. Pure voxels have real 16³ sparse chunks, hidden-face removal and greedy meshing. Increasing building scale keeps the voxel size fixed but gives each architectural feature more cells. The camera normalizes scale for a fair comparison; 4× buildings with 25 cm voxels give 6.25 cm effective detail. Very fine combinations are limited to keep this prototype practical. Coarse grids lose lettering, narrow frames and smooth curves. Hybrid keeps precise cladding, glazing and trim over a voxel structure.

Select Remove voxel or Add voxel, then click the voxel model. Undo reverses your edit; Reset edits restores it. Changing the grid also resets edits. Outdoor walking footprints stay fixed during this material comparison.

Frame rate covers all visible panels together. GPU buffer and voxel storage figures are separate estimates, not total browser memory. Generation timings include meshing. This page generates all three versions from one small download.
